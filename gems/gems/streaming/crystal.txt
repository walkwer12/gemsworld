Open PowerShell.
Check Python:
python --version
Check Java:
java -version
Check PySpark:
python -m pip show pyspark
Check Hadoop configuration:
echo $env:HADOOP_HOME
Confirm:
•	Python is installed.
•	Java is accessible.
•	PySpark is installed (the previously used environment had PySpark 4.2.0).
•	Existing Hadoop configuration is working.
No need to reinstall PySpark or Hadoop if everything is working.
Note: Python's socket module is built in, so it does not need a separate installation.
________________________________________
B. Create project folder
Open PowerShell.
mkdir BD_P5
cd BD_P5
Open this folder in VS Code.
Create two Python files:
1.	Socket_sender.py
2.	word_count_stream.py
Copy the respective programs from your journal into these files and save them.
________________________________________
C. Execute the socket sender program
PowerShell – Terminal 1
Make sure you are inside the BD_P5 folder.
python Socket_sender.py
Wait until you see:
======================================
Socket Server Started
Waiting for Spark to connect...
Host: localhost
Port: 9999
======================================
The socket server is now waiting for Spark to connect.
Important: Keep this terminal running. Do not enter messages yet.
________________________________________
D. Execute the Spark Structured Streaming program
Open a second PowerShell terminal in VS Code.
Make sure the second terminal is also inside the BD_P5 folder.
PowerShell – Terminal 2
python word_count_stream.py
Spark will start and connect to the socket server.
Return to Terminal 1.
Wait until you see:
Spark connected!
Start entering messages.
Type 'exit' to stop.
--------------------------------------
This confirms that Spark has connected successfully.
________________________________________
E. Send messages and observe word count
PowerShell – Terminal 1
Enter the following messages one at a time:
hello world
hello spark hello python hello spark
Press Enter after each message.
PowerShell – Terminal 2
Observe the word counts displayed by Spark.
The final counts should include:
Word	Count
hello	4
world	1
spark	2
python	1
The output may appear in separate batches. Spark displays the updated aggregation table because the program uses outputMode("complete").
________________________________________
F. Stop the programs
PowerShell – Terminal 1
Type:
exit
This closes the socket sender connection.
PowerShell – Terminal 2
Press:
Ctrl + C
This stops the Spark streaming application.
Important: Typing exit in the sender terminal does not automatically stop the Spark query. Stop Spark separately using Ctrl + C.
________________________________________
G. Successful execution checklist
•	Python, Java and PySpark are accessible.
•	Project folder BD_P5 is created.
•	Both Python files are saved.
•	Socket server starts on localhost, port 9999.
•	Spark Structured Streaming application starts.
•	Spark successfully connects to the socket server.
•	Messages are entered through the sender terminal.
•	Spark receives and processes the messages.
•	Words are split into individual rows.
•	Word counts are displayed in the Spark terminal.
•	Final counts are correct: hello = 4, world = 1, spark = 2, python = 1.
•	Both programs are stopped properly.
________________________________________
H. Troubleshooting
Error / Problem	What to do
ModuleNotFoundError: No module named 'pyspark'	Run python -m pip install pyspark using the same Python interpreter.
JAVA_HOME is not set	Check Java installation and JAVA_HOME configuration.
Winutils.exe or Hadoop error	Check your existing C:\hadoop\bin configuration. Do not reinstall Hadoop immediately.
ConnectionRefusedError	Start Socket_sender.py first, then run word_count_stream.py in the second terminal.
Address already in use	Check whether an earlier socket sender is still running. Stop it before starting another.
Port 9999 already in use	Close the previous socket server or check which process is using the port.
Spark is not connecting	Confirm both programs use localhost and port 9999.
No word counts appear	Enter a message in Terminal 1 and press Enter. Check that Spark is still running in Terminal 2.
ModuleNotFoundError: pyspark despite installation	Check python --version and python -m pip show pyspark to ensure the same Python interpreter is being used.
Spark keeps running after typing exit	This is expected. Press Ctrl + C in Terminal 2 to stop Spark.
________________________________________
Important execution order:
1.	Start Socket_sender.py in Terminal 1.
2.	Start word_count_stream.py in Terminal 2.
3.	Wait for Spark to connect.
4.	Enter messages in Terminal 1.
5.	Observe word counts in Terminal 2.
6.	Type exit in Terminal 1.
7.	Press Ctrl + C in Terminal 2.
Do not start the Spark program before the socket sender is listening.
