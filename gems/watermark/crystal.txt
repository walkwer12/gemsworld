A. Initial setup – One-time checks
Open PowerShell.

Check Python:
python --version

Check Java:
java -version

Check whether PyFlink is installed:
python -m pip show apache-flink

Verify that Python can import PyFlink:
python -c "import pyflink; print('PyFlink is working')"

Confirm:
•	Python is installed.
•	Java is accessible.
•	PyFlink is installed and can be imported.
•	You are using the intended Python interpreter.

If PyFlink is missing, install it:
python -m pip install apache-flink

Do not reinstall it if it is already working.

B. Create project folder
mkdir BD_P7
cd BD_P7

Open this folder in VS Code.

Create one Python file:
latedata.py
Copy the Practical 7 program from your journal into this file and save it.

Important: retain the journal's env.set_python_executable(sys.executable) line.

C. Execute the program
PowerShell – Terminal 1
Make sure you are inside the BD_P7 folder.

Run:
python latedata.py

Wait for the Flink job to execute.
The job name configured in the program is:
Food Delivery Late Data

The program should print the main-window output and any events captured by the late-data side output.

D. Understand the expected event arrangement

The journal uses these four events:
Event	Event timestamp
Picked up	1,000 ms
At restaurant	8,000 ms
Delivered	22,000 ms
Order confirmed	3,000 ms

The program uses:
•	Watermark delay: 2 seconds
•	Window type: Tumbling Event-Time Window
•	Window duration: 10 seconds
•	Late-event output tag: late_events

The event-time windows are:
Window	Events based on timestamps
0–10 seconds	Picked up, At restaurant, Order confirmed
10–20 seconds	No events
20–30 seconds	Delivered

Important: Order confirmed arrives last despite having an earlier event timestamp. It is intended to demonstrate out-of-order data. However, the journal's finite collection and reduction logic do not guarantee that this event will visibly appear in the late side output. Do not assume that seeing the program finish proves late-event capture worked.
E. Successful execution checklist
•	Python starts successfully.
•	PyFlink imports without errors.
•	Flink execution environment is created.
•	Parallelism is set to 1.
•	Four delivery events are created.
•	Event timestamps are assigned using DeliveryTimestampAssigner.
•	Watermark strategy is configured with a 2-second delay.
•	10-second tumbling event-time windows are created.
•	Late-event side output is configured using late_tag.
•	Main output and late output are printed.
•	Flink job executes with the name Food Delivery Late Data.

F. Troubleshooting
Error	What to do
ModuleNotFoundError: No module named 'pyflink'	Run python -m pip install apache-flink using the same Python interpreter.

python is not recognized	Check Python installation and PATH configuration.

JAVA_HOME is not set or Java-related error	Check Java installation and JAVA_HOME configuration.

PyFlink import fails after installation	Run python -m pip show apache-flink and confirm that the package is installed for the Python interpreter being used.

Python worker or executable error	Ensure env.set_python_executable(sys.executable) is present in the program.

Program exits with an exception	Read the complete PowerShell traceback and identify the first reported error.

No late events appear	Check the watermark progression and window-closing behaviour. Remember that the journal's reduce(lambda a, b: a) only retains the first event in each window.

Wrong file or folder error	Run cd BD_P7 and confirm the file is named latedata.py.
